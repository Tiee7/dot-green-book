## 发布验收办法

GitHub 仓库需要确认 Public 与 MIT 许可；Pages 使用 GitHub Actions。每次发布应等待 Actions 的构建及部署完成，然后实际打开首页、问答锚点和章节深层路径，确认加载到本次内容。绿色构建本身不替代在线检查。
